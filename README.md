Experienced Infrastructure Engineer dedicated exclusively to the convergence of **Artificial Intelligence**, **Cloud Security (SecOps)**, and **Automated Governance**. My mission is to build secure architectures using advanced AI-driven workflows with a strictly **Human-in-the-loop** approach.
